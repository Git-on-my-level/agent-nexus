# Agent Nexus v0.13.66

## What's Changed

- Store card revision manifests without prose bodies (#549). Card revision
  artifacts keep their complete raw access edges but store only reference atoms
  in `artifacts.content_refs_json`; a bounded, resumable backfill prunes legacy
  manifests after verifying the authoritative revision content. Revision
  content bytes and authorization decisions are unchanged.
- Drop four redundant workspace indexes (#549). Migration 147 removes indexes
  whose work is already covered by a wider index or that no query reads.

## Upgrade and rollback

Take a fresh per-workspace backup before upgrading. Migrations 139 (v0.13.65),
142 and 147 are forward-only. Do not start v0.13.65 or older against a 142+
database: older binaries do not register the `anx_resource_without_prose`
scalar used by migration 142's artifact-update trigger, so artifact updates
fail. Rollback means restoring the pre-upgrade backup; there is no in-place
downgrade.
